**Basic Editor Layout**

![image05](legacy/iulv-42apzmr8yaw-qfd61.jpg)

**The website editor has four areas:**

- Main menu

- Format bar

- Pages manager

- Website view

**Main menu**

This is the area where you will find most of the features available in the website builder. You will find more details in the following pages.

**Format bar**

Every element has individual options and customization settings. Select any element, and you will find the controls for these options and settings in the format bar.

**Pages manager**

Here you can manage your website structure and move, duplicate, rename pages and more.

**Website view**

This is the WYSIWYG (what you see is what you get) drag and drop editing environment. You can select, edit, move, scale (and much more) all the elements in your website here.

**File menu**

![image11](legacy/iulv-70oauxsjvp0k-un9tg.jpg)

**Save draft**

Saves your website, but does not publish it online. This is useful when you are in the process of making changes, but are not ready to publish them online yet.

**Publish online**

Saves your website, and publishes the changes directly online on your webspace and or domain.

**Download all my files**

Saves a backup of all the files you uploaded into your website, for example images and PDF downloads.

**Export site / Import site**

Saves a backup copy of your website in the Cabanova format, on your local computer. “Export” saves a copy on your device, and “Import” lets you load it back into Cabanova, replacing the current website you have.

**Collaborate**

Feature is currently not active.

**Close editor / Logout**

Choosing “Close editor” will take you back to the “My Cabanova” dashboard, while “Logout” will log you out of your account completely.

**Edit menu**

![image04](legacy/iulv-6uceac6nw2m1-ucwy9.jpg)

**Undo / Redo**

No matter what you do, you can always undo it in in case you change your mind. The number of steps you can undo is unlimited from the time you load the editor until you close the editor again.

**Delete, Cut, copy, paste**

Basic editing options for any element

**Duplicate**

Copies and pastes the currently selected element.

**Select all**

When editing pages: Selects all the elements on your page, excluding the elements in your template.

When editing template: Selects all the items in your template

**Deselect**

Deselects and elements you have currently selected.

**Order**

Move elements to the front or back, or move them one step at a time.

**Template menu**

![image08](legacy/iulv-d6vr5e5k8ge-wce8c.jpg)

**Edit template**

This starts the template editing mode. Any changes you make will be visible on every page.

**Change template**

You can choose a new template from the library at any time. Doing so will replace your current template completely, but will not affect any of the content in your individual pages.

**Choose template color**

here you will find various color schemes for your selected template.

**Add predefined pages**

Every template comes with a number of pages containing predefined content. You can add these pages to your website.

**Favicon**

This is the little icon that appears in the browser tab when someone visits your website. You can upload a JPG or PNG file here to set it as your favicon.

**Insert menu**

![image01](legacy/iulv-2j0cm2sabat6-lfyfy.jpg)

This is the menu where you can find all the elements available for you to add to your template and pages.

**Generic**

Text, image, button, table

**Media**

Gallery, video, sound

**Social media**

Facebook, Twitter, Google+

**Forms**

Predefined forms, e.g. basic and advanced contact forms

Individual form elements: Single line field, multiline field, date, check box, radio button, dropdown menu, file upload, submit button.

**Shapes**

Circle, rectangle, rounded rectangle, polygon, star, wedge, gear

**More elements**

Poll guestbook, counter, navigation, Google map, custom HTML, external content, search.

**Page menu**

![image03](legacy/iulv-7b8v52oagb21-j3lq9.jpg)

**List page content**

Opens a list with all the elements you have on your page.

**Page background**

This is the background behind your website. When editing your template, the background you set will be visible on all your pages by default. You can also set a different background for any selected page.

As a background you can set a solid color, gradient or upload an image.

**Page HTML**

Use this feature to insert custom HTML source code above or below your currently selected page.

**Hide this page in navigation**

You can create pages that are not listed in your website navigation.

**Hide navigation on this page**

You can use this option to remove the navigation element from your currently selected page.

**Page password**

You can password-protect a page here.

**SEO menu**

![image07](legacy/iulv-51yci9tpzfjj-31h12.jpg)

**Page metadata**

Set page titles, descriptions and keywords here.

**Page images**

Set alt-texts for the images on your pages.

**Google analytics**

Connect your website with your Google analytics account.

**Google webmaster tools**

Connect your website with your Google Webmaster Tools account.

**Google sitemap**

Here you will find the URL of a sitemap that Cabanova created for your website. You need this when setting up your Google Webmaster Tools.

**Robots**

Here you can upload a robots.txt file. This file informs search engines about the pages you don’t want to be indexed.

**View menu**

![image00](legacy/iulv-40d1duol9hpq-qsigy.jpg)

**View draft site**

View the last saved draft version of your website.

**View published sites**

View your published website live online.

**Selection info**

Displays information about the currently selected element.

**Zoom 50 - 110%**

If you load the editor on mobile devices with small screens, you can zoom in the editor menus.

**Enter full screen**

To maximize your screen real estate, you can take the website editor fullscreen.

**Translation**

This is where the various language versions are managed. This feature is not available for regular end-users.

**Mobile menu**

![image10](legacy/iulv-34tqy1wz1lr5-j0lyg.jpg)

**Mobile panel**

Here you can manage the responsive design mobile version of your website. When people visiting your published website are using a mobile device with a small screen, they will see this one-column optimized version. You can set the general style of your mobile version, and choose which elements from your regular website you want to have displayed in your mobile pages.

Whenever you add new elements in your website, be sure to open the Mobile Panel and add them to your mobile version also.

**Pages Manager**

![image09](legacy/iulv-5yuredjw1hgr-7ys1a.jpg)

This is where you manage the pages in your website.

To open the pages manager, hit the grey hamburger menu ( ) at the top left of the page.

**You can do the following to your pages:**

- Add a new page

- Duplicate

- Delete

- Link

- Move

- Rename

- Hide page in navigation
