**You may set up your email accounts in Outlook 2003 by following these instructions:**

- Within Microsoft Outlook, go to "**Tools** " and select "**E-mail accounts** "

![outlook-tools-emailaccounts](legacy/iulv-2udimq8xyp9x-5v4z0.jpg)

- Select "**Add a new e-mail account** " and hit "**Next** "

![outlook-add-new-account](legacy/iulv-36a3ny004lf9-pkdg0.jpg)

- Select "**POP3** " as Server Type and click on "**Next** "

![outlook-servertype-pop3](legacy/iulv-3apyhq1cukxh-fjhy7.jpg)

**Fill-in the requested information as follows (see also image below):1. User Information:**

Your name: Enter your full name

E-mail address: Enter the full e-mail address

**2. Server Information:**

Incoming mail server (POP3): **pop.cabanova.com**

Outgoing mail server (SMTP): **smtp.cabanova.com3. Logon Information:**

User name: Enter the **full e-mail address**

Password: Enter the email account password you set

![outlook-email-settings](legacy/iulv-3cjxsqxu5myd-sbe3e.jpg)

- Then hit the "**More settings** " button and click on the "**Outgoing Server** " tab in the "**Internet E-mail Settings** " window and:

- Select **My outgoing server (SMTP) requires authentication** .

- Select **Use same settings as my incoming mail server** .

![outlook-smtp-authentification](legacy/iulv-44qmp9i19ee-ggo48.jpg)

- Now click on the "**Advanced** " tab in the "**Internet E-mail Settings** " window and enter the following settings:

- Set the **Incoming Server**  (**POP3** ) port to: **995**

- Check "**This server requires an encrypted connection**  (**SSL** )"

- Set the **Outgoing Server**  (**SMTP** ) port to: **465**

- Check "**This server requires an encrypted connection**  (**SSL** )"

![outlook-advanced-settings](legacy/iulv-8plj1a2l2vq-8vnw9.jpg)

- Hit "**OK** " to close the "**Internet E-mail Settings** " window

![outlook-email-settings (1)](legacy/iulv-3cjxsqxu5myd-sbe3e.jpg)

- Click on "**Next** " then "Finish" to close the "**E-mail Accounts** " window

![outlook-finished](legacy/iulv-fsfxjxp5ck6-84mo5.jpg)
