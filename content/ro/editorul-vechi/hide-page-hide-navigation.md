In the **Page**  ribbon **[1]**  you can find **Hide this page in navigation [2]**  and **Hide navigation on this page [3]** .

![hide-page](legacy/iulv-2mof4i0dmj73-fqs6i.jpg)

You can use **Hide this page in navigation [2]**  to remove a page from the navigation bar.

And you can use **Hide navigation on this page [3]**  if you don't want the navigaton bar to be diplayed on a certain page.
