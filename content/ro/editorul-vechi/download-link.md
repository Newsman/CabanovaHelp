You can have a **download link**  where to upload your files for other people to see and/or download. To do that select the element you want to link, click on the **link icon [1]** , select **Download Link [2]** , select what **the link will do [3]**  (start the download when someone clicks on it or open the file in new window). You can add **Protected Downloads [4]**  (remember if you want to have a protected file you must select Protected Downloads when you add a file). To add a file click on **Add File [5]** , you can **Delete File [6]**  if you no longer need it and you can **Open File [7]**  to see it.

![download-link](legacy/iulv-5mqzyfwwthx0-7gcps.jpg)

**Note:**  The files will be uploaded on the site, so you can acces them from any element with **Download Link** .
