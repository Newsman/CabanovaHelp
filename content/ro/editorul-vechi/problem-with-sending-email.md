If you setup your POP3 email account in Outlook and you can receive but not send emails, please follow the instructions below:

**For Outlook 2003**

- Start Outlook, go to '**Tools** ' and select '**E-mail Accounts...** '

![website-troubleshooting-email-accounts](legacy/iulv-15pk12q1vj5e-uherr.jpg)

- Select '**View or change existing email accounts** ' and hit '**Next** '

![website-troubleshooting-email-change-existing-email](legacy/iulv-1jte72110ng2-8batf.jpg)

- Select the email account you're having sending issues with and hit '**Change** '

![website-troubleshooting-email-settings-change](legacy/iulv-1obciwwy8qsy-gfmbf.jpg)

- On the '**Internet E-mail Settings (POP3)** ' window, click on '**More Settings...** '

![website-troubleshooting-email-settings-more](legacy/iulv-1sy7qh8jo3oy-3yb6.jpg)

![website-troubleshooting-email-settings-outgoing-server](legacy/iulv-697wermcficv-503q7.jpg)

- Hit '**Next** ' then '**Finish** ' to validate the changes

![website-troubleshooting-email-settings-finish](legacy/iulv-6fwn7mk44z3j-sx919.jpg)

**For Outlook 2007**

- Launch Outlook; go to '**Tools** ' and select '**Account Settings...** '

![website-troubleshooting-email-outlook2007-account-settings](legacy/iulv-6knqhmrd42i7-wys4b.jpg)

- Select the email account you're having sending issues with and hit '**Change** '

![website-troubleshooting-email-outlook2007-settings-change](legacy/iulv-6q6n5a1mqz73-vvim.jpg)

- Click on '**More Settings...** ' and go to the '**Outgoing Server** ' tab

![website-troubleshooting-email-outlook2007-settings-more](legacy/iulv-6wy81acuim5r-n1pq5.jpg)

- Check the box '**My outgoing server (SMTP) requires authentication** '

- Select '**Use same settings as my incoming mail server** ' - if not selected by default - then hit '**OK** '

![website-troubleshooting-email-outlook2007-settings-outgoing-server](legacy/iulv-42mmvpxjj6ia-4o7bf.jpg)

- Click on '**Next** ' then hit '**Finish** ' to validate the changes

**For Outlook 2010**

- Start Outlook, go to the '**File** ' ribbon and click on '**Account Settings** '

- Click on '**More Settings...** ' and go to the '**Outgoing Server** ' tab

- Check the box '**My outgoing server (SMTP) requires authentication** '

- Select '**Use same settings as my incoming mail server** ' - if not selected by default - then hit '**OK** '

- Click on '**Next** ' then hit '**Finish** ' to validate the changes.

If following the above instructions doesn't help to fix the issue, please follow this link to entirely review your email account settings.
