**Text, Image, Button, Table** , this are the generic elements, in other words the most used elements.

**Text:**  You can add a text by clicking on **Insert [1]**  and click on **Text [2]** . Its a text field, can have unlimited lines and can be edited from the "**Editing tool bar** ". You can select **Text Styles**  and predefine them to be used in the entire website, this is helpful when you want to change the format of the text in the entire site.

![text](legacy/iulv-63rqnf5xkoo5-iwpih.jpg)

**Image:**  You cand add any **image [1]**  from **your Computer [2]** , or you can add them from our **Library [3]** , from **Flickr [4]** , **Dropbox [5]**  or **GoogleDrive [6]** .

![insert image](legacy/iulv-24xa3g6tqe9d-91b2k.jpg)

**Button:**  We have a big list of buttons for you to choose from, **Rectangle, Rounded, Pill, Circle, Border, Glow, 3D, Glass, Push, Shiny, Drop Shadow, Lite, Glossy**  or **Beveled**  Buttons.

Also as text have **Text style** , button have **Button Style** , where you can edit your button as you like.

![Buttons](legacy/iulv-6q7tbtw03edp-t85wr.jpg)

![Button styles](legacy/iulv-6uet4rmu4lfx-sb0sa.jpg)

**Table:**  To create a Table, go to Insert, click on table, then click on how many rows and columns you want to add. You can move the mouse up or down and left or right do increase or decrease the number of rows and columns, you can also edit that after you insert the table from the "**Editing tool bar** ".

![Table](legacy/iulv-6w1fndh2eikt-lfqk7.jpg)

**Editing tool bar**  is differen from element to element, and it contains all the possible editing option for the selected element. Each element has "**Undo** ", "**Redo** " and "**Delete** " as the first options. The "**Undo** " and "**Redo** " are global while "**Delete** " apears only when you sellect an item, when nothing is selected you can "**Insert new element** " from the same spot.

- The **Text**  elment has the following options:

Text Style - can edit the format of the text for the entire site.You have to create, and apply to your text the style you want in order to be modified later(if you so choose).

**Font**  - Changes the font of the text.

**Size -**  Changes the size of the text.

**Bold** ,Italic,Underline - Makes the text bold,italic or underlined.

**Align -**  Aligns the text to left center or right.

**List -**  Creates a list.

**Color -**  You can color the text and also the textfield and can add borders.

**Padding -**  Increase or decrease the margins.

**Spacing -**  Increase or decrease the space between the lines.

**Animation -**  Can add animation to your text field.

**Effects -**  You can add transparency, drop shadow or make your text hold it's position if you scroll down or up.

**Link -**  you can link your text (or just a part of it) to an external link, to a page withing this site, to an email, to download a file, to an action.

![text tool bar](legacy/iulv-6yivnpgoh1u5-rpy24.jpg)

- **Image**  element has the following options:

**Crop -**  You can crop your image inside our editor.

**Frame -**  You can add frames to your image.

**Animation -**  Can add animation to your image.

**Effects -**  You can add transparency, drop shadow, reflection or make your image hold it's position if you scroll down or up.

**Link -**  you can link your image to an external link, to a page withing this site, to an email, to download a file, to an action.

![Image tool bar](legacy/iulv-7d1un8tjg9l9-6udoe.jpg)

- **Button**  element has the following options:

**Button Style -**  can edit the format of the button for the entire site.You have to create, and apply to your button the style you want in order to be modified later(if you so choose).

**Text Format -**  You can modify the format of the text inside the button.

**Color Styles -**  Here you can edit the color of the button, unlike the button style, this editing will only be applied only to the selected button.

**Rounding -**  Makes the button sharper or smoother from 0%(sharp) to 100%(smooth)

**Label -**  This changes the text inside the button.

**Animation -**  Can add animation to your button.

**Effects -**  You can add transparency, drop shadow or make your button hold it's position if you scroll down or up.

**Link -**  you can link your button to an external link, to a page withing this site, to an email, to download a file, to an action.

![Button tool bar](legacy/iulv-7jram4phzrm5-bada7.jpg)

- **Table**  element has the following options:

**Padding -**  Increases or decreases the padding top and left, here you can also add or delete rows and columns.

**Insert/Delete -**  You can insert/delete rows and columns.

**Font -**  Select the font of selected text.

**Size -**  Select the size of selected text.

**Bold,Italic,Underline -**  Make the selected text bold,italic or underlined.

**Align -**  Align the selected text to left center or right.

**Vertical align -**  Align the selected text up center or down.

**List -**  Create a list with the selected text.

**Color -**  Color the selected text.

**Line color -**  Color the lines of the table.

**Fill -**  Fill the seleced table box.

**Animation -**  Can add animation to your table.

**Effects -** You can add transparency, drop shadow or make your table hold it's position if you scroll down or up.

**Link -**  you can link text in your table to an external link, to a page withing this site, to an email, to download a file, to an action.

![table  tool bar](legacy/iulv-czjo94cuaa6-rw3r6.jpg)
