If after updating and republishing your Website, you can not view the changes online, we advise you to clear your Internet browser cache by following the instructions below:

**1. If your Internet browser is Internet Explorer:**

- Launch Internet Explorer, go to '**Tools** ' **[a]**  and select '**Internet Options** ' **[b]**

![website-problem-solving-cache-ie-options](legacy/iulv-5k3yynmvn92p-clags.jpg)

- Hit 'Delete' at the '**Browsing History** ' section level **[a]**  then select '**Temporary Internet files** ' **[b]**  (Leave other checkboxes unselected) then hit '**Delete** ' **[c]**

![website-problem-solving-cache-ie-options-browsing-history](legacy/iulv-5uf0gyulf1yp-z1im.jpg)

![website-problem-solving-cache-ie-options-browsing-history-delete](legacy/iulv-67lfx3h182pd-w42ke.jpg)

- Then on '**Internet Options** ' window, click on '**Apply** ' **[a]**  and '**OK** ' **[b]**

![website-problem-solving-cache-ie-options-apply](legacy/iulv-6kpq3ca1mg8h-r9vxk.jpg)

**2. If your Internet browser is Firefox:**

- Launch Firefox, go to '**Tools** ' **[a]**  and select '**Clear Recent History** ' **[b]**

![website-problem-solving-cache-ff-options](legacy/iulv-gset8yvmzos-13ai4.jpg)

- From the '**Time range to clear** ' dropdown list, select '**Everything** ' **[a]** , select only '**Cache** ' from the '**Details** ' section**[b]**  and hit '**Clear Now** ' **[c]**

![website-problem-solving-cache-ff-options-clear-all-history](legacy/iulv-51ypz6seypvt-o9hc9.jpg)

**3. If your Internet browser is Google Chrome:**

- Launch Google Chrome, hit the **Wrench**  icon **[a]** , select '**Tools** ' **[b]**  then click on '**Clear browsing data...** ' **[c]**

![website-problem-solving-cache-chrome-options](legacy/iulv-2deslqm05xrd-60j3r.jpg)

- Select the '**the beginning of tine** ' from the '**Obliterate the following items from** ' **[a]**

- Select '**Empty the cache** ' **[b]**

- Then hit '**Clear browsing data** ' **[c]**

![website-problem-solving-cache-chrome-options-clear-browsing-data](legacy/iulv-2pwioojofj1l-nnkhu.jpg)

**4. If your Internet browser is Safari:**

- Launch Safari, click on the **Cog**  icon **[a]**  and select '**Show Menu Bar** ' **[b]**

(Skip this step if the menu bar is already displayed on Safari and go to the next step).

![website-problem-solving-cache-safari-menubar](legacy/iulv-2zq068v9wdnt-1po7b.jpg)

- On the menu bar, click on 'Edit' [a] and select 'Empty Cache...' [b]

![website-problem-solving-cache-safari-options](legacy/iulv-36ko0fe88vmx-x00bv.jpg)

- Hit '**Empty** ' **[a]**  on the diplayed dialog box

![website-problem-solving-cache-safari-options-empty](legacy/iulv-3d9tchh1d5ih-5ui6s.jpg)

**If clearing your Internet browser cache doesn't solve the issue, please follow these instructions:**

- Download and install the CCleaner Tool by [**clicking here**](http://www.piriform.com/ccleaner/download/standard)

- Once the download is finished, close your Internet browser

- Locate the '**ccsetup.exe** ' file and double-click on it to launch the installation

- Follow the instructions on the screen to complete the installation then launch CCleaner by double-clicking on the CCleaner icon on your Desktop

- On the vertical left menu of CCleaner, click on '**Cleaner** '

- Then hit the '**Analyze** ' button and run the Cleaner by clicking on '**Run Cleaner** '

- Wait for the operation to complete then restart your Internet browser
